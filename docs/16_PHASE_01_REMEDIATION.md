# المرحلة الأولى من الاستكمال — الأساس والإعدادات

الإصدار: 2.1.0  
الحالة: حزمة مرحلية، وليست نهائية.

## المنفذ

- ترقية Dexie v3 غير هدامة مع الحفاظ على v1 وv2 واسم `BuildingManagerDB`.
- هوية العمارة: الاسم والعنوان والهاتف والبريد والملاحظات والشعار والصورة.
- تخزين الشعار والصورة كـBlob مضغوط في جدول المرفقات.
- إعدادات العملة والرمز والمنازل العشرية والرصيد الافتتاحي وتاريخه.
- إدارة قوائم طرق الدفع وتصنيفات الإيرادات والمصروفات والصيانة.
- إعدادات ضغط الصور وأنواع الملفات والتنبيهات.
- Currency Context موحد لعرض المبالغ حسب الإعدادات.
- معالجة QuotaExceededError برسالة عربية.
- إصلاح أمر البناء في البيئة الحالية باستخدام Vite config runner.

## التحقق

- `npm install`: ناجح.
- `npm run typecheck`: ناجح.
- `npm run build`: ناجح.
- إنشاء Manifest وService Worker: ناجح.
- فتح صفحة الإعدادات من حزمة الإنتاج والمسار الفرعي: ناجح.

## مؤجل للمراحل التالية

CRUD الكامل للشقق والسكان، الفلاتر، إيصال PDF، تذكير WhatsApp الفردي، مرفقات العمليات، أنواع التقارير واختبارات القبول الكاملة.
