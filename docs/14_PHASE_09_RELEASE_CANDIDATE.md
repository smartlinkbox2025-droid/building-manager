# المرحلة التاسعة — الإصدار المرشح والتنظيف

الإصدار: 1.9.0

## المنجز

- تثبيت نطاقات إصدارات الحزم وإزالة `latest` بالكامل.
- نقل `@vitejs/plugin-react` إلى devDependencies.
- توحيد إصدار التطبيق بين package.json وقاعدة البيانات.
- إضافة فحص بنيوي مستقل يعمل دون تنزيل الحزم.
- التحقق من بقاء اسم قاعدة البيانات ومخططات Dexie السابقة.
- التحقق من وجود 19 جدولاً أساسياً في IndexedDB.
- التحقق من جميع مسارات الصفحات الأساسية.
- التحقق من إعداد PWA وManifest وGitHub Actions والأيقونات.
- دمج الفحص البنيوي داخل أمر البناء لمنع إصدار نسخة ناقصة.

## أوامر التحقق

```bash
npm run validate
npm run typecheck
npm run build
npm run check
```

## نتيجة البيئة الحالية

نجح `npm run validate` في 38 بنداً. تعذر تنزيل حزم npm في بيئة التنفيذ بسبب انتهاء مهلة الاتصال، ولذلك يبقى فحص TypeScript والبناء الإنتاجي الكامل مطلوباً عند توفر اتصال بمستودع npm.
