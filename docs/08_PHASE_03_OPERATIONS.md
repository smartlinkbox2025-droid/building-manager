# المرحلة الثالثة — العمليات التشغيلية

- تشغيل المبالغ الإضافية الشهرية ككيانات مستقلة مرتبطة بالشقة والشهر والاستحقاق.
- إضافة خدمة الإلغاء المنطقي للمبالغ الإضافية وإعادة حساب إجمالي الاستحقاق.
- إضافة صفحات فعلية للمشتريات والموردين والإيرادات الأخرى.
- حساب إجمالي المشتريات تلقائياً من الكمية وسعر الوحدة والضريبة.
- إضافة إدارة عقود الصيانة والمواعيد القادمة.
- إدخال المشتريات المدفوعة ضمن معادلة رصيد الصندوق والتقارير.
- تسجيل العمليات الجديدة داخل سجل الحركات.
