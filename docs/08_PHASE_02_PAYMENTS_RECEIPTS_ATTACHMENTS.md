# المرحلة الثانية: الدفعات والإيصالات والمرفقات

## المنجز

- إنشاء خدمة مستقلة لتسجيل الدفعات والتحقق من القيم المالية.
- توليد رقم إيصال فريد داخل معاملة Dexie باستخدام جدول التسلسل.
- عدم إعادة استخدام أرقام الإيصالات بعد الإلغاء.
- إنشاء سجل إيصال مستقل Snapshot لكل دفعة.
- تحديث حالة الاستحقاق تلقائياً بعد التسجيل أو الإلغاء.
- دعم الدفعات المتعددة لنفس الاستحقاق.
- إضافة إلغاء منطقي للدفعة مع سبب إلزامي وسجل حركة.
- إضافة رفع إثبات الدفع وربطه بالدفعة.
- ضغط الصور قبل تخزينها داخل IndexedDB.
- تنزيل إثبات الدفع مع تحرير Object URL.
- توسيع النسخة الاحتياطية لتشمل جميع الجداول والمرفقات بصيغة Blob.
- التحقق من metadata وبنية النسخة قبل الاستعادة.

## التوافق

تم الحفاظ على حقول `extras` القديمة في الاستحقاقات، مع استخدام جدول `extraCharges` عند وجود سجلات جديدة، لضمان عدم فقدان أو تجاهل البيانات السابقة.
