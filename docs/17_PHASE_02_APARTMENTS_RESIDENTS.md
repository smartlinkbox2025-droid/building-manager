# المرحلة الثانية — الشقق والسكان

الإصدار: 2.2.0  
الحالة: حزمة مرحلية، وليست نهائية.

## المنفذ

- CRUD غير هدّام للشقق والسكان: إضافة وتعديل وتعطيل وإعادة تفعيل.
- حقول الوحدة والإشغال وبداية الاستحقاق.
- بحث وفلاتر وفرز وترقيم صفحات مع حفظ حالة الفلاتر في sessionStorage.
- تصدير PDF وExcel للنتائج المفلترة.
- صيغة دولية لرقم الجوال.
- سجل دفعات المشترك المرتبط بالشقة.
- Audit لكل إضافة وتعديل وتعطيل وإعادة تفعيل.

## التحقق

- TypeScript Strict: ناجح.
- اختبارات البناء: موثقة في سجل التسليم.
- اسم قاعدة البيانات ومخططات v1/v2/v3 محفوظة.
