# المرحلة الأولى: تثبيت أساس البيانات والعلاقات

## الهدف
ترقية قاعدة البيانات الحالية تدريجياً دون إعادة كتابة المشروع أو حذف أي جدول أو بيانات قائمة.

## ما تم تنفيذه
- الإبقاء على قاعدة البيانات نفسها باسم `BuildingManagerDB`.
- الإبقاء على الإصدار الأول كما هو لضمان قراءة البيانات القديمة.
- إضافة مخطط Dexie إصدار 2 مع ترقية آمنة للبيانات الحالية.
- إضافة الكيانات الناقصة: بنود الاشتراك، المبالغ الإضافية، الإيصالات، المشتريات، الموردون، عقود الصيانة، المرفقات، التنبيهات، تسلسل الإيصالات ومعلومات إصدار قاعدة البيانات.
- توسيع الأنواع الحالية بحقوق اختيارية حتى لا تنكسر الصفحات القديمة.
- إضافة خدمة حسابات مالية مركزية لحساب المطلوب والمدفوع والمتبقي وحالة الدفع.
- إضافة قيم افتراضية للإعدادات الجديدة أثناء ترقية البيانات.

## حماية البيانات
- لم يتغير اسم قاعدة IndexedDB.
- لم يتم حذف أي جدول موجود.
- الحقول الجديدة اختيارية في الأنواع القديمة.
- الترقية تستخدم Dexie upgrade وتضيف القيم الافتراضية فقط عند غيابها.

## المرحلة التالية
ربط تسلسل الإيصالات والمعاملات المالية بخدمات فعلية، ثم تطوير الاشتراكات لدعم عدة دفعات ومبالغ إضافية مستقلة.
