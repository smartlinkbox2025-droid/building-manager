# المرحلة الرابعة — العمليات والصيانة

الإصدار: 2.4.0  
الحالة: حزمة مرحلية، وليست نهائية.

## المنفذ

- المصروفات والإيرادات والمشتريات والموردون: إضافة وتعديل وإلغاء/تعطيل.
- حالة دفع المصروف ومركز التكلفة ورقم الفاتورة والمرجع.
- مرفقات وفواتير لكل عملية مع ضغط ومعاينة وتنزيل وحذف منطقي.
- أعمال الصيانة بكل التواريخ والتكاليف والحالات والتكرار.
- عقود الصيانة بكل بيانات الدفع والمسؤول والتنبيه والمرفق.
- Audit للقيم السابقة والجديدة وأسباب الإلغاء.
- بحث وتصدير للبيانات الظاهرة.

## الحماية

- لا حذف نهائي للسجلات المالية.
- لا قيم مالية سالبة.
- تبقى المرفقات مرتبطة بمعرف العملية.
- اسم قاعدة البيانات ومخططات v1/v2/v3 محفوظة.
