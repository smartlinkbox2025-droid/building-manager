# المرحلة السادسة: التأهيل

الإصدار: 2.6.0

## إضافات التأهيل

- تهيئة Tailwind CSS مع المحافظة على تصميم التطبيق الأصلي.
- تنبيه استخدام مساحة التخزين عند بلوغ 80٪.
- فحوص آلية للبنية المالية، قاعدة البيانات، PDF، Excel، النسخ الاحتياطي، PWA ومسار GitHub Pages.
- منشئ XLSX محلي مبني على JSZip بدلاً من SheetJS، مع اختبار فتح بنية الأرشيف وRTL والتجميد والفلترة.
- تحويل PDF الإيصالات والتقارير إلى رندر المتصفح بخط Amiri بعد أن كشف الفحص البصري خللاً في تشكيل النص المختلط داخل محرك PDF النصي.
- الإبقاء على `BuildingManagerDB` ومخططات Dexie 1 و2 و3 بلا حذف أو إعادة تسمية.

## أوامر التحقق

```bash
npm install
npm run typecheck
npm run acceptance
```

نجح اختبار الأوفلاين فعلياً بإيقاف خادم المعاينة بعد الزيارة الأولى ثم إعادة تحميل المسار الفرعي من Service Worker.

## قيد وصف النسخة

هذه حزمة تأهيل. اختبار «التثبيت على الهاتف» يحتاج هاتفاً حقيقياً ورابط HTTPS منشوراً، لذلك لا يجوز وصف الحزمة بالنهائية قبل توثيق نجاحه.
