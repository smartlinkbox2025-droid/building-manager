# المرحلة السادسة — لوحة التحكم والتنبيهات

الإصدار: 1.6.0

## المنجز
- لوحة تحكم مرتبطة مباشرة ببيانات IndexedDB.
- مؤشرات الرصيد والإيرادات والمصروفات والمتأخرات وحالات السداد.
- نسبة تحصيل الشهر وأرقام الشقق المتأخرة.
- حركة مالية لآخر ستة أشهر.
- آخر الدفعات والمصروفات والمشتريات.
- الصيانة القادمة والعقود القريبة.
- خدمة تنبيهات تعيد بناء التنبيهات عند فتح اللوحة.
- تنبيهات الاشتراكات المتأخرة والصيانة والعقود والنسخ الاحتياطي.
- حفظ حالة قراءة التنبيه.
- دعم اختياري لـ Notification API دون الاعتماد عليه.

## سلامة البيانات
لم تتغير أسماء قاعدة البيانات أو الجداول السابقة، ولم تُحذف أي بيانات أو ميزة. التنبيهات مشتقة من البيانات الحالية وتُخزن في جدول alerts الموجود مسبقاً.
