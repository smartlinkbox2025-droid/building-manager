# المرحلة الخامسة: التقارير والنسخ الاحتياطي والتدقيق

الإصدار: 2.5.0

## المنجز

- إضافة 13 نوع تقرير قابل للتصفية والتصدير إلى Excel وPDF.
- إنشاء PDF عربي بخط Amiri المحلي مع عنوان المبنى والفلاتر وتاريخ التصدير وترقيم الصفحات.
- توسيع Excel إلى أوراق متعددة مع التجميد والفلترة.
- تنظيم مرفقات النسخة الاحتياطية في مجلدات دلالية ورفع `formatVersion` إلى 3 مع إبقاء استعادة الإصدارين 1 و2.
- إظهار القيم السابقة والجديدة في سجل العمليات وإضافة مرشحات التاريخ.
- تسجيل حدث اكتمال الحذف الشامل بعد إنشاء قاعدة فارغة، ومنع استعادة اسم المبنى المحذوف.

## التحقق

تُشغّل أوامر التثبيت وفحص TypeScript والبناء قبل تغليف هذه المرحلة.
