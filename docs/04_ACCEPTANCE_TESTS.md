# اختبارات القبول النهائية

1. إضافة بيانات العمارة والشعار ثم ظهورهما في لوحة التحكم والتقارير.
2. إضافة شقتين ومنع تكرار رقم الشقة.
3. إضافة مشترك وربطه بشقة.
4. إنشاء استحقاق شهري بالقيمة الافتراضية.
5. تخصيص قيمة مختلفة لشقة واحدة.
6. إنشاء استحقاقات شهر محدد دون تكرار.
7. إضافة بندين إضافيين لشقة واحدة في شهر واحد.
8. التأكد من عدم انتقال البنود إلى الشهر التالي.
9. تسجيل دفعة جزئية.
10. تسجيل دفعة ثانية لنفس الاستحقاق.
11. تغير الحالة تلقائياً من غير مدفوع إلى جزئي ثم مدفوع.
12. إنشاء رقم إيصال فريد لكل دفعة.
13. رفع إثبات دفع وضغطه.
14. معاينة وتنزيل إثبات الدفع.
15. إنشاء إيصال PDF عربي سليم.
16. فتح رسالة WhatsApp صحيحة للشقة المتأخرة.
17. تسجيل مصروف مع فاتورة.
18. تسجيل شراء وحساب الإجمالي.
19. تسجيل صيانة دورية مع موعد قادم.
20. تسجيل عقد وإظهار تنبيه قبل انتهائه.
21. إنشاء تقرير مالي يحتوي تفاصيل المصروفات.
22. تصدير PDF عربي متعدد الصفحات دون تفكك الحروف.
23. تصدير Excel RTL منسق.
24. تطبيق فلتر شهر وتصدير نتائج الفلتر فقط.
25. إنشاء نسخة احتياطية تشمل المرفقات.
26. استعادة نسخة واسترجاع السجلات والمرفقات.
27. رفض ملف نسخة غير صالح دون فقدان البيانات.
28. ظهور القديم والجديد في سجل العمليات.
29. عمل التطبيق أوفلاين بعد أول زيارة.
30. تثبيت التطبيق على الهاتف.
31. عمل التطبيق من مسار GitHub Pages الفرعي.
32. ترقية إصدار قاعدة البيانات دون فقدان بيانات الإصدار السابق.
33. حذف جميع البيانات فقط بعد كتابة العبارة والتأكيد النهائي.
