# المرحلة السابعة — التصدير والمشاركة

الإصدار: 1.7.0

## المنجز
- تطوير PDF متعدد الصفحات مع ترقيم الصفحة من إجمالي الصفحات.
- إنشاء PDF كملف قابل للمشاركة عبر Web Share API.
- إضافة مشاركة التقرير ونسخ الملخص وفتح WhatsApp بالنص فقط.
- إضافة ملف Excel متعدد الأوراق للملخص والمصروفات والمشتريات والاستحقاقات.
- دعم RTL ودمج خلايا الترويسة والفلاتر وتجميد صف العناوين في Excel.
- إضافة قوالب WhatsApp منفصلة للتذكير وملخص التقرير واسم الجهة المرسلة.
- الحفاظ على التصدير من البيانات المفلترة فقط.
