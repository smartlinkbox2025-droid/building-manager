## ملاحظات تقنية حرجة

1. `Charge.extras` قيمة واحدة وليست قائمة بنود مستقلة؛ يجب إنشاء جدول `chargeExtras`.
2. لا يوجد جدول للمرفقات، الإيصالات، العقود، المشتريات، الموردين، التنبيهات، أو تسلسل الإيصالات.
3. PDF الحالي صورة Canvas للعنصر، وليس PDF عربي احترافي قابل للبحث متعدد الصفحات.
4. النسخ الاحتياطي لا يدعم Blobs أو التحقق الكامل أو الدمج.
5. بعض الملفات مضغوطة في أسطر طويلة جداً، ما يصعب الصيانة والاختبار.
6. الحزم تستخدم `latest`، وهذا يسبب عدم ثبات البناء مستقبلاً.
7. يجب إضافة migrations لـ Dexie بدلاً من تعديل version 1 مباشرة.
