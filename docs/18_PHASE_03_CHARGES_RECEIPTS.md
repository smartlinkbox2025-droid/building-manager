# المرحلة الثالثة — الاشتراكات والإيصالات

الإصدار: 2.3.0  
الحالة: حزمة مرحلية، وليست نهائية.

## المنفذ

- توليد جماعي للاستحقاقات الشهرية.
- فلاتر الاشتراكات وتصدير النتائج الظاهرة.
- دفعات جزئية ومتعددة وحالة تلقائية.
- أرقام إيصالات ذرية وفريدة.
- مبالغ إضافية مستقلة مع تعديل/إلغاء موثق.
- إثبات دفع مضغوط مع عرض وتنزيل واستبدال وحذف.
- إيصال PDF مستقل بخط Amiri محلي (OFL) وشعار العمارة.
- مشاركة الإيصال وتذكير WhatsApp الفردي.

## تحقق سيناريو المتصفح

- إنشاء استحقاق لشقة مرتبطة بمشترك: ناجح.
- إضافة مبلغ 30 ر.س للشهر المحدد: ناجح.
- دفعة أولى 50 ر.س: الحالة أصبحت مدفوعاً جزئياً.
- دفعة ثانية 100 ر.س: الحالة أصبحت مدفوعاً بالكامل.
- رقما الإيصال: `INV-2026-201-001` و`INV-2026-201-002`.
- أزرار إيصال PDF والمشاركة والمرفقات ظاهرة لكل دفعة.
