# خارطة تنفيذ Enterprise v1.0

## المرحلة 0 — تثبيت الأساس

- تثبيت إصدارات الحزم بدلاً من `latest`.
- إنشاء `package-lock.json`.
- تنسيق الملفات وتقسيم الأسطر الطويلة.
- إضافة Error Boundary ورسائل أخطاء موحدة.
- تثبيت رقم إصدار التطبيق وقاعدة البيانات.
- إنشاء نسخة احتياطية من بيانات المستخدم قبل أول Migration.

**معيار الإغلاق:** نجاح `npm install` و`npm run build` وعدم تغير السلوك الحالي.

## المرحلة 1 — نموذج البيانات الآمن

إضافة Dexie version 2 وما بعدها مع جداول:

- `chargeExtras`
- `receipts`
- `attachments`
- `purchases`
- `maintenanceContracts`
- `suppliers`
- `alerts`
- `receiptSequences`
- `backupHistory`
- `appMeta`

وتوسعة الكيانات الحالية دون حذف الحقول القديمة.

**معيار الإغلاق:** ترقية قاعدة بيانات موجودة دون فقدان أي سجل.

## المرحلة 2 — الشقق والسكان

- إضافة وتعديل وتعطيل وإعادة تفعيل.
