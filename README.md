# إدارة العمارة السكنية PWA

تطبيق عربي يعمل دون خادم لإدارة الشقق والسكان والاشتراكات والدفعات والإيرادات والمصروفات والصيانة والتقارير.

## التشغيل محلياً

```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج

```bash
npm run build
```

سيتم إنشاء مجلد `dist` الجاهز للنشر.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً في GitHub.
2. ارفع جميع ملفات المشروع إلى الفرع `main`.
3. افتح Settings > Pages.
4. اختر Source: GitHub Actions.
5. سيعمل ملف `.github/workflows/deploy.yml` تلقائياً.
6. سيظهر رابط التطبيق بعد اكتمال النشر.

## التخزين

تُحفظ البيانات داخل IndexedDB في متصفح الجهاز. حذف بيانات المتصفح قد يحذف بيانات التطبيق، لذلك استخدم النسخة الاحتياطية ZIP بانتظام من صفحة الإعدادات.

## تثبيت التطبيق

بعد فتح الرابط في Chrome أو Edge، استخدم خيار "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
