# إدارة العمارة السكنية PWA

تطبيق عربي يعمل دون خادم لإدارة الشقق والسكان والاشتراكات والدفعات والإيرادات والمصروفات والصيانة والتقارير.

## التشغيل محلياً

```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج

```bash
npm run build
```

سيتم إنشاء مجلد `dist` الجاهز للنشر.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً في GitHub.
2. ارفع جميع ملفات المشروع إلى الفرع `main`.
3. افتح Settings > Pages.
4. اختر Source: GitHub Actions.
5. سيعمل ملف `.github/workflows/deploy.yml` تلقائياً.
6. سيظهر رابط التطبيق بعد اكتمال النشر.

## التخزين

تُحفظ البيانات داخل IndexedDB في متصفح الجهاز. حذف بيانات المتصفح قد يحذف بيانات التطبيق، لذلك استخدم النسخة الاحتياطية ZIP بانتظام من صفحة الإعدادات.

## تثبيت التطبيق

بعد فتح الرابط في Chrome أو Edge، استخدم خيار "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".

## التحقق قبل النشر

نفّذ الأوامر التالية قبل رفع أي إصدار:

```bash
npm install
npm run validate
npm run check
npm run acceptance
```

يقوم `npm run validate` بفحص بنية المشروع، إصدار التطبيق، قاعدة البيانات، الجداول، المسارات، إعداد PWA وملفات GitHub Pages قبل بدء بناء الإنتاج.


## حالة الاكتمال

المشروع قيد الاستكمال وفق تقرير التدقيق وخطة المراحل. لا تُوصف أي حزمة بأنها نهائية قبل نجاح اختبارات القبول الـ32.

الفحص البنيوي يعمل عبر:

```bash
npm run validate
```

والتحقق الكامل في بيئة متصلة بالإنترنت:

```bash
npm install
npm run check
```

راجع تقرير التدقيق وخطة المراحل، ثم ملفات `docs/17_...` حتى `docs/21_...` لمعرفة التغييرات والتحقق في كل مرحلة.
